【电脑音乐播放器与多媒体远程遥控器 使用说明】

一、电脑端使用：
1. 确保电脑已打开音乐播放器（网易云音乐、QQ音乐、酷狗、Spotify 等），并开启全局快捷键。
2. 双击打开本目录下的 music_switcher.exe。
3. 黑色窗口中会显示出你的“手机访问地址”（例如：http://192.168.x.x:10010/）。

二、快捷键适配说明：
本程序向电脑发送的标准全局按键如下：
- 播放/暂停: Ctrl + Alt + P
- 上一首:     Ctrl + Alt + Left
- 下一首:     Ctrl + Alt + Right
- 音量加:     Ctrl + Alt + Up
- 音量减:     Ctrl + Alt + Down
默认完全对齐网易云音乐全局快捷键；若使用 QQ 音乐或其它播放器，只要在软件设置中将全局快捷键设为上述组合即可通用控制！

三、手机端控制（两种方式任意选一种）：

方式 1（最简单，免安装 App）：
在与电脑连接同一 WiFi 的手机上，直接打开手机浏览器，在地址栏输入电脑窗口提示的网址（如 http://192.168.x.x:10010/），即可直接用网页上的大按钮切歌、调音量。

方式 2（安装安卓 App）：
把本目录下的 网易云音乐手机遥控端.apk（或 navie_client.apk_1.0.apk）传到安卓手机上安装，打开 App 后输入电脑窗口显示的 IP 地址即可连接控制。
