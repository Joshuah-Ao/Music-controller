【电脑音乐播放器与多媒体远程遥控器 使用说明】

一、电脑端使用：
1. 确保电脑已打开音乐播放器（网易云音乐、QQ音乐、酷狗、Spotify 等），并开启全局快捷键。
2. 双击打开本目录下的 music_switcher.exe。
3. 黑色窗口中会显示出你的“手机访问地址”（例如：http://192.168.x.x:10010/）。

二、按键映射说明：
- 播放/暂停: Ctrl + Alt + P
- 上一首:     Ctrl + Alt + Left
- 下一首:     Ctrl + Alt + Right
- 音量加:     Ctrl + Alt + Up
- 音量减:     Ctrl + Alt + Down
- 一键睡眠:   Win + Space（切英文防中文干扰） -> Win + X -> U -> S
- 安全关机:   5 秒安全切断电脑电源

三、手机端控制（两种方式任意选一种）：

方式 1（极力推荐，全新暗夜玻璃拟态网页版）：
在与电脑连接同一 WiFi 的手机上，直接打开手机浏览器，在地址栏输入电脑窗口提示的网址（如 http://192.168.x.x:10010/）。
页面采用全异步 AJAX 交互，点击不刷新页面，支持触控反馈、一键睡眠与关机防误触弹窗。

方式 2（安装安卓 App 客户端）：
把本目录下的 网易云音乐手机遥控端.apk 传到安卓手机上安装，打开 App 后输入电脑窗口显示的 IP 地址即可连接控制。
