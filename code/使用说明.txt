【电脑音乐播放器与多媒体远程遥控器 使用说明 (v1.3.0)】

一、电脑端使用：
1. 确保电脑已打开音乐播放器（网易云音乐、QQ音乐、酷狗、Spotify 等），并开启全局快捷键。
2. 双击打开本目录下的 music_switcher.exe。
3. 黑色窗口中会显示出你的“手机访问地址”（例如：http://192.168.x.x:10010/）。

二、按键映射与功能说明：
- 播放/暂停: Ctrl + Alt + P（支持双向动态状态与图标律动切换）
- 上一首:     Ctrl + Alt + Left（切歌自动同步为播放中状态）
- 下一首:     Ctrl + Alt + Right（切歌自动同步为播放中状态）
- 音量加:     Ctrl + Alt + Up
- 音量减:     Ctrl + Alt + Down
- 喜欢歌曲:   Ctrl + Alt + L（支持多端同步喜欢状态与“取消喜欢二次确认”防误触；锁屏/状态栏需 3 秒内双击确认，长按按钮可仅同步标记不发快捷键）
- 进度条与红心同步: 优先连接网易云远程调试端口 (--remote-debugging-port=9222) 读取真实进度、支持进度条拖动与真实红心状态同步；未开启时自动回退 Windows SMTC（若网易云未打开，服务端会自动带 9222 参数启动；若已打开绝不打断听歌，建议在网易云快捷方式“目标”末尾加上空格和 --remote-debugging-port=9222）
- 一键睡眠:   Win + Space（自动切英文输入法，避免中文干扰） -> Win + X -> U -> S
- 安全关机:   带有防误触确认弹窗，确认后 5 秒安全切断电脑电源

三、手机端控制（两种方式任意选一种）：

方式 1（免安装网页版 v1.3）：
在与电脑连接同一 WiFi 的手机上，直接打开手机浏览器，在地址栏输入电脑窗口提示的网址（如 http://192.168.x.x:10010/）。
- 顶部实时显示当前曲名、歌手、播放来源与可拖动进度条（支持 ±10s 微调）。
- 新增“❤️ 喜欢”按钮，桌面浏览器同样支持按下 Ctrl + Alt + L 触发。
- 播放/暂停大按钮具有实时双向图标切换与极光流光律动动效。

方式 2（纯原生安卓 App 客户端 v1.3）：
把本目录下的《手机遥控端.apk》传到安卓手机上安装。
- 新增【锁屏界面控制 & 状态栏控制】：基于 Android 原生 MediaSession + MediaStyle，连接电脑后常驻状态栏与锁屏媒体卡片，息屏点亮即可切歌、暂停、喜欢和拖动进度条（可在 App 内随时开关）。
- 新增【喜欢快捷键】与【播放进度条控制】：支持进度条拖动、±10s 快进快退与实时曲目同步。
- 支持 Android 5.0 至 Android 15 全版本，自动记忆电脑 IP 地址。
