【电脑音乐播放器与多媒体远程遥控器 使用说明 (v1.2.0)】

一、电脑端使用：
1. 确保电脑已打开音乐播放器（网易云音乐、QQ音乐、酷狗、Spotify 等），并开启全局快捷键。
2. 双击打开本目录下的 music_switcher.exe。
3. 黑色窗口中会显示出你的“手机访问地址”（例如：http://192.168.x.x:10010/）。

二、按键映射与功能说明：
- 播放/暂停: Ctrl + Alt + P（支持双向动态状态与图标律动切换）
- 上一首:     Ctrl + Alt + Left（切歌自动同步为播放中状态）
- 下一首:     Ctrl + Alt + Right（切歌自动同步为播放中状态）
- 音量加:     Ctrl + Alt + Up
- 音量减:     Ctrl + Alt + Down
- 一键睡眠:   Win + Space（自动切英文输入法，避免中文干扰） -> Win + X -> U -> S
- 安全关机:   带有防误触确认弹窗，确认后 5 秒安全切断电脑电源

三、手机端控制（两种方式任意选一种）：

方式 1（极力推荐，全新暗夜玻璃拟态网页版）：
在与电脑连接同一 WiFi 的手机上，直接打开手机浏览器，在地址栏输入电脑窗口提示的网址（如 http://192.168.x.x:10010/）。
- 播放/暂停大按钮具有实时双向图标切换与极光流光律动动效。
- 页面采用全异步 AJAX 交互，点击不刷新页面，支持触控反馈、一键睡眠与关机防误触弹窗。
- 零安装、零权限要求、永不闪退，在浏览器菜单中选择“添加到主屏幕”即可作为桌面 App 体验。

方式 2（全新重构超轻量原生安卓 App 客户端 v1.2，彻底解决闪退）：
把本目录下的《网易云音乐手机遥控端.apk》传到安卓手机上安装。
- 针对现代安卓系统彻底重构：彻底移除了 2015 年遗留的 32 位 React Native 限制，原生支持 64 位（arm64-v8a）与全系芯片架构，彻底解决在新手机上打开闪退的问题！
- 支持 Android 5.0 至 Android 15 全版本，已开启明文 HTTP 权限，局域网连接稳定通畅。
- 极速轻量：安装包仅约 38KB，毫秒级秒开，内存占用极低。
- 自动记忆 IP：首次输入电脑 IP 地址并连接后，App 将自动保存，下次打开自动填入并握手。
- 全新暗黑深色卡片布局（#0B0F17），支持“🌙 一键睡眠”与“⛔ 安全关机”防误触确认弹窗。
