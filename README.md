# NetEaseMusicController (网易云音乐远程遥控器)

> 躺在床上用手机远程控制电脑上的网易云音乐播放、切歌、调音量与关机，支持手机浏览器免安装与安卓客户端。

---

## ✨ 核心特性

- 🎵 **完整播放控制**：上一首、下一首、暂停/播放、音量调高/调低、远程关机。
- ⚡ **原生快捷键适配**：全面适配网易云音乐当前默认的全局快捷键（`Ctrl + Alt + 方向键 / P`），**无需在网易云音乐中修改任何快捷键设置**！
- 🚀 **开箱即用免安装**：服务端已打包为独立绿色版可执行文件，无 Python 环境也能双击秒开。
- 📱 **双端远程支持**：
  - **免安装网页端（推荐）**：局域网内任意手机、平板浏览器打开即可控制，触控大按键防误触。
  - **安卓 App 客户端**：提供打包好的 Android `.apk` 客户端安装包。
- 🛡 **零历史依赖**：去除已废弃的老旧 C 扩展库依赖，升级为原生底层键盘模拟，稳定流畅。

## 🚀 快速上手

### 1. 下载运行服务端 (电脑端)
前往本项目的 [Releases (发行版)](https://github.com/Joshuah-Ao/Music-controller/releases) 页面，下载 `music_switcher.exe` 与资源包。

双击运行 `music_switcher.exe`，窗口中会自动打印出服务信息与手机端访问地址，例如：
```text
============================================================
 网易云音乐远程控制服务已就绪！
 电脑访问地址: http://127.0.0.1:10010/
 手机访问地址: http://192.168.x.x:10010/
============================================================
```

### 2. 手机端控制 (二选一)

#### 方式 A：手机浏览器直接控制（推荐，免装 App）
确保手机和电脑连接在同一个 WiFi 局域网下：
1. 打开手机浏览器（Safari、Chrome、自带浏览器等）；
2. 在地址栏直接输入电脑窗口显示的手机访问地址（如 `http://192.168.1.4:10010/`）；
3. 即可进入触屏大按钮遥控页面，随时随地切歌和调节音量！

#### 方式 B：安装安卓 App 客户端
1. 在 Releases 页面下载 `网易云音乐手机遥控端.apk` 并安装至安卓手机；
2. 打开 App，输入电脑提示的 IP 地址（如 `192.168.1.4:10010`），点击连接即可。

## ⌨️ 快捷键映射对照表

本程序向系统发送的标准全局快捷键如下（与网易云音乐默认设置完全一致）：

| 功能 | 对应全局按键 |
| :--- | :--- |
| **播放 / 暂停** | `Ctrl + Alt + P` |
| **上一首** | `Ctrl + Alt + Left` (左箭头) |
| **下一首** | `Ctrl + Alt + Right` (右箭头) |
| **音量加** | `Ctrl + Alt + Up` (上箭头) |
| **音量减** | `Ctrl + Alt + Down` (下箭头) |
| **远程关机** | 电脑将在 5 秒后安全关机 |

*(注：确保网易云音乐已勾选开启全局快捷键即可。)*

## 🛠 从源码运行

如果你希望直接运行或二次开发 Python 源码：

```bash
cd ne_music_controller
python music_switcher.py
```
本版本已内置原生自适应服务，无需额外执行 `pip install` 即可开箱运行。
