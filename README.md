# Music Controller (PC 音乐播放器与多媒体远程遥控器)

> 躺在床上用手机远程控制电脑上的音乐播放、切歌、调音量、一键睡眠与关机。不仅完美支持网易云音乐，还广泛兼容 QQ音乐、Spotify、各类影音播放器与 PPT 演示！支持高颜值手机网页端免安装与安卓客户端。

---

## ✨ 核心特性

- 🎵 **通用播放控制**：上一首、下一首、暂停/播放、系统音量调高/调低。
- 🌙 **全新一键睡眠**：
  - 手机点击一键睡眠，电脑自动先执行 `Win + Space` 切换为英文输入状态（防中文输入法拦截），再精准通过 `Win + X > U > S` 触发电脑系统休眠/睡眠，睡前无需起身！
- ⚡ **开箱即用，多平台兼容**：
  - 默认预设适配网易云音乐官方全局快捷键（`Ctrl + Alt + 方向键 / P`），**无需在网易云中修改任何设置**。
  - **不仅局限于网易云**：只要在 **QQ音乐、酷狗音乐、Spotify、Foobar2000** 等播放器中将全局快捷键设为相同组合，即可无缝通用控制！
  - 同样可扩展控制 **PotPlayer / 恒星播放器** 等视频软件暂停快进，或作为 **PPT 幻灯片无线翻页笔** 使用。
- 🎨 **全新高颜值 UI 界面**：
  - **网页端**：采用现代暗夜流光与磨砂玻璃拟态（Glassmorphism）设计，支持全异步 AJAX 无刷新点击，带有轻触震动反馈与关机防误触确认。
  - **安卓端**：升级深色极简卡片风格，新增一键睡眠独立操作按钮。
- 🚀 **绿色免安装**：服务端已打包为独立绿色版可执行文件（`music_switcher.exe`），无需安装或配置任何 Python 环境，双击即用。
- 📱 **双端远程支持**：
  - **免安装网页端（最推荐）**：局域网内任意手机、平板浏览器打开即可控制，触控大按键防误触，iOS 与 Android 全平台通用。
  - **安卓 App 客户端**：提供重新打包签名好的 Android `.apk` 客户端安装包。
- 🛡 **底层原生驱动**：基于 Windows 底层键盘事件模拟，免去老旧依赖，稳定流畅不卡顿。

## 🚀 快速上手

### 1. 启动服务端 (电脑端)
前往本项目的 [Releases (发行版)](https://github.com/Joshuah-Ao/Music-controller/releases) 页面，下载 `music_switcher.exe`。

双击运行 `music_switcher.exe`，黑色窗口中会自动打印出服务信息与手机端访问地址，例如：
```text
============================================================
 音乐播放器远程控制服务已就绪！
 电脑访问地址: http://127.0.0.1:10010/
 手机访问地址: http://192.168.x.x:10010/
============================================================
```

### 2. 手机端控制 (二选一)

#### 方式 A：手机浏览器直接控制（推荐，免装 App）
确保手机和电脑连接在同一个 WiFi 局域网下：
1. 打开手机浏览器（Safari、Chrome、自带浏览器等）；
2. 在地址栏直接输入电脑窗口显示的手机访问地址（如 `http://192.168.1.4:10010/`）；
3. 即可进入触屏大按钮高颜值遥控页面，随时随地切歌、调音量或一键睡眠！

#### 方式 B：安装安卓 App 客户端
1. 在 Releases 页面下载 `网易云音乐手机遥控端.apk` 并安装至安卓手机；
2. 打开 App，输入电脑提示的 IP 地址（如 `192.168.1.4:10010`），点击连接即可。

## ⌨️ 快捷键映射对照表

本程序向系统发送的标准全局快捷键如下：

| 功能 | 模拟的按键序列 / 全局按键 | 作用说明 |
| :--- | :--- | :--- |
| **播放 / 暂停** | `Ctrl + Alt + P` | 网易云音乐、QQ音乐等主流播放器 |
| **上一首** | `Ctrl + Alt + Left` (左箭头) | 音乐切歌 / 视频快退 / PPT 上一页 |
| **下一首** | `Ctrl + Alt + Right` (右箭头) | 音乐切歌 / 视频快进 / PPT 下一页 |
| **音量加** | `Ctrl + Alt + Up` (上箭头) | 系统音量增大 |
| **音量减** | `Ctrl + Alt + Down` (下箭头) | 系统音量减小 |
| **一键睡眠** | `Win + Space` ➔ `Win + X` ➔ `U` ➔ `S` | 先切英文状态，再通过系统超级菜单平滑睡眠 |
| **安全关机** | 触发安全关机指令 | 电脑将在 5 秒后安全切断电源 |

```bash
cd ne_music_controller

```
